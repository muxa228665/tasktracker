# Трекер задач

Веб-приложение для управления задачами на **React + Vite** с голубой цветовой темой.

## Возможности

- ➕ Добавление задач с приоритетом и сроком
- ✅ Отметка задач как выполненных
- ✏️ Редактирование названия (двойной клик по тексту или иконка карандаша)
- 🗑️ Удаление задач
- 🔍 Поиск по названию
- 🗂️ Фильтры: все / активные / выполненные
- 📊 Статистика: прогресс-бар, счётчики, число задач с высоким приоритетом
- ⏰ Подсветка просроченных задач
- 💾 Автосохранение в `localStorage`
- 📱 Адаптивная вёрстка

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # запуск в режиме разработки (http://localhost:5173)
npm run build    # сборка для продакшена в папку dist
npm run preview  # предпросмотр продакшен-сборки
```

```
    ├── App.jsx             # логика и состояние приложения
    ├── index.css           # глобальные стили и голубая тема
    ├── hooks/

        ├── FilterBar.jsx
        ├── TaskList.jsx

```
